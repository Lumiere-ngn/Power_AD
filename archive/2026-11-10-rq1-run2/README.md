# Archive of the second RQ1 run (10 November 2026)

The second run of `analysis/rq1.py`, without the `demo` (6) and `show` (1) units (decision D6). It was the second
scoring of 1 August to 6 October; the first run is in `archive/2026-11-10-rq1-run1/`. After reading these results the
user asked for the `buspas` units (10) to be left out as well, so RQ1 was redone a third time. That third run is a
further deviation, recorded in the deviation log of `analysis/protocol/PROTOCOL.md`, and its results replace these in
`analysis/protocol/RESULTS_RQ1.md`.

| File | Content |
|---|---|
| `RESULTS_RQ1.md` | Results text of the second run |
| `out/rq1_dev.json`, `out/rq1_dev.log`, `out/rq1_locked.json` | Development stage and locked settings |
| `out/rq1_test.json`, `out/rq1_test.log`, `out/rq1_test_predictions.parquet` | The test, as scored the second time |
| `rq1.py`, `rq_common.py` | The scripts as they were for this run |

Large files (`*.parquet`, `*.log`) are ignored by git; they exist only on this machine.
The Google Docs copy of these results is "RQ1 results (10 November 2026, v3, without demo and show units)".
